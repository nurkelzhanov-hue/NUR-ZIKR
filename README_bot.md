# NUR ZIKR boti: ornatıw (1-qádem)

1. Telegramda @BotFather → /newbot → atın jazıń → TOKEN alıń.
2. index.html di GitHub Pages ke qoyıń (HTTPS silteme shıǵadı).
3. Kompyuter yamasa serverde bir papkaǵa qoyıń: bot.py, hadislar.json, requirements.txt
4. Ornatıw hám iske túsiriw:
   pip install -r requirements.txt
   BOT_TOKEN="TOKEN" WEBAPP_URL="https://SIZ.github.io/REPO/index.html" python3 bot.py
5. Telegramda botqa /start jazıń: NUR ZIKR túymesi shıǵadı.

Bot toqtamay islep turıwı kerek (server yamasa ózińizdiń kompyuter).
